Customate.ai Widget Demo

This page demonstrates how the Customate.ai chat widget can be embedded in your website. You can configure various options below:

Widget Configuration

Embed Code

<script src="https://widget.customate.ai/widget.js"></script>
<script>
  CustomateWidget.init({
    apiKey: 'YOUR_API_KEY',
    primaryColor: '#4f46e5',
    position: 'bottom-right',
    greeting: 'Hello! How can I help you today?'
  });
</script>
